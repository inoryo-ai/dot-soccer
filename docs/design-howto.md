# 画面を自分で触るための手引き（.soccer）

オーナーが**自分の手で**色・余白・大きさを詰めるための道具と決まり。
AIに任せきりにせず、見ながら数字を決めたいときに読む。

---

## 1. まず往復をなくす

```
npm run build:web   ← 最初に1回だけ（TypeScript を組み立てる）
npm run dev         ← これを出しっぱなしにする
```

→ **http://localhost:4174/**

| 触るもの | 反映 |
|---|---|
| `web/style.css` | **保存して再読み込みするだけ**（ビルド不要） |
| `web/index.html` | 同じく再読み込みだけ |
| `src/**/*.ts` | `npm run build:web` を回してから再読み込み |

🔑 `npm run dev` は `web/`（手で書いたもの）を先に見て、無ければ `web/dist/`
（組み立てたもの）へ落とす。だから**CSSとHTMLは手で触れて、コードは触らなくていい**。

🔴 これは開発用。本番に出すのは必ず `npm run build:web` が作る `web/dist/`。

---

## 2. 色と寸法は**34個のつまみ**に集まっている

`web/style.css` のいちばん上、`:root { ... }` の中だけで画面全体の見た目が決まる。
個別の箇所を直すより、**ここを変えるほうが速くて、ズレない**。

### 地（画面の背景）

| つまみ | いまの値 | 何に効くか |
|---|---|---|
| `--paper` | `#f6ead0` | 一番下の地。少し黄みのある紙 |
| `--paper-dark` | `#e7d6b4` | 地の陰。溝や目地 |
| `--panel` | `#fffdf3` | パネルの面。ほぼ白だが白にしない（枠が浮くため） |
| `--panel-sunk` | `#efe3c6` | 沈んだ面。入力欄・表の縞 |

### 輪郭と文字

| つまみ | いまの値 | 何に効くか |
|---|---|---|
| `--edge` | `#3b2a1b` | 🔴 **枠はこの1色だけ**。太さで意味を分ける |
| `--edge-soft` | `#9a8463` | 意味を持たない仕切り線だけ |
| `--bevel` | `#ffffff` | 面の上辺に入れる光。立ち上がりを出す |
| `--ink` | `#33261a` | 本文 |
| `--ink-dim` | `#7d6a51` | 補足・注記 |
| `--ink-on-dark` | `#fffdf3` | 濃い面の上の文字 |

### UIの青（2026-10-02 のラフで主役にした色）

| つまみ | いまの値 | 何に効くか |
|---|---|---|
| `--ui` | `#2f7ed8` | 見出しの帯・ボタン |
| `--ui-lt` | `#58a4ea` | 帯の上側（明るいほう） |
| `--ui-dk` | `#1a5aa8` | 帯の下側（暗いほう） |
| `--ui-edge` | `#14407a` | 青い部品の枠 |

🔑 帯は上を明るく下を暗くする2段にしてある。**平らな青はシールに見える。**

### 役割の色（🔴 用途を混ぜない）

| つまみ | いまの値 | 何に効くか |
|---|---|---|
| `--home` / `--home-dark` | `#f2a714` / `#c7820a` | 自チーム。画面で一番目立つ |
| `--away` / `--away-dark` | `#3d8ed6` / `#2a6ba6` | 相手チーム |
| `--accent` / `--accent-dark` | `#2fa85a` / `#1f7a40` | 進める操作 |
| `--danger` / `--danger-dark` | `#e2574c` / `#b23a31` | 取り返しがつかない操作 |
| `--warn` | `#e08a1e` | 注意 |
| `--gk` | `#e2574c` | ゴールキーパー |

🔴 `--gk` は値が `--danger` と同じだが**意味が違うので変数を分けてある**。
`--danger` を直に使うと「GKは危険」という読み方が生まれ、あとで危険色だけ変えたときに
GKのユニフォームまで一緒に変わる。

### 芝

| つまみ | いまの値 |
|---|---|
| `--turf` / `--turf-dark` | `#3fae5a` / `#37a04f` |
| `--line` | `#eafbee` |

🔴 **試合の3D描画はCSSを見ていない。** 芝と選手の色は `src/web/field3d.ts` と
`src/web/match3d.ts` の中にある。CSSの `--turf` は配置盤やミニマップなど**HTML側**だけ。
両方そろえたいときは言ってもらえれば合わせる。

### 寸法（🔴 ここが一番大事）

| つまみ | いまの値 | 何に効くか |
|---|---|---|
| `--px` | `2px`（画面幅1200px以上で `3px`） | **すべての寸法の単位** |
| `--w-hair` | `--px` | 仕切り線 |
| `--w-frame` | `--px × 2` | 面の枠 |
| `--w-pop` | `--px × 3` | 前に出ているもの（モーダル・得点） |
| `--drop` | `--px × 2` | 影のずれ（**ぼかさない**） |
| `--gap` | `--px × 4` | 基本の間隔 |
| `--bar-h` | `--px × 26` | 下のコマンド帯の高さ |

🔴 **寸法は必ず `calc(var(--px) * n)` で書く。** 生の `px` を書かない。
`--px` を 2 → 3 に変えると画面全体が一段大きくなる、という仕組みが崩れる。

🔴 **枠の太さは意味を持つ。** 3種類しか使わない。4種類目を足すと、
太さから意味が読めなくなる。

## 3. 数字を決めるときのやり方

### A. ブラウザで当たりをつける（セットアップ不要）

1. http://localhost:4174/ を開く
2. `F12` → 左上の矢印アイコンで変えたい部分をクリック
3. 右の **Styles** で `:root` を探し、値を直接書き換える（色は四角をクリックでピッカー）
4. 気に入った値をメモして、`web/style.css` の `:root` に書く

🔑 DevTools の数値は**上下キーで1ずつ動く**（Shiftで10ずつ）。色より余白を詰めるときに速い。

### B. ファイルを直接書き換える

`web/style.css` の `:root` を編集 → 保存 → 再読み込み。それだけ。

## 4. やっていいこと／やらないほうがいいこと

### ✅ 自由にやっていい

- `:root` の色をどれだけ変えても壊れない
- `--px` を変えて全体の大きさを変える
- 個別の見た目（角丸・影・字の大きさ）を足す

### ⚠ 気をつける

- **寸法に生の px を書かない**（上の決まり）
- **枠の太さを4種類目にしない**
- `[hidden] { display: none !important }` を消さない
  🔴 これが無いと、`display: grid` を持つ要素が `hidden` を無視して出っぱなしになる
  （ゴールの演出が消えなくなった実例がある）
- `.screen` / `.is-on` の仕組みは画面の出し分けそのもの。見た目以外は変えない

### ❌ ここは触らない

- `web/dist/` — 組み立てた成果物。直してもビルドで消える
- `src/**/*.ts` — コード。見た目の指示をもらえればこちらで直す

## 5. 変えたあと

```
npm run check    ← 画面のコードが名指ししている id がHTMLにあるか等を見る
```

色と余白だけなら通らなくなることはまずない。HTMLの構造を触ったときだけ要注意。

変更はそのまま置いておいてもらえれば、こちらで取り込んでコミットする。
**自分で戻したくなったら** `git checkout web/style.css` で元に戻る。
