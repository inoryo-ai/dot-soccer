# 画面の見た目を、絵で渡すための場所

言葉で細かく指示するより、**作ったものを見せるほうが速くて正確**。その受け渡し場所。

```
docs/design/
  current/   いまの画面のスクリーンショット（1920×1080）。赤入れの下地に使う
  in/        オーナーが渡すもの（Canva などで作った指示書・素材）
```

---

## 置き方

`docs/design/in/` にファイルを置いて、**ファイル名を伝えるだけ**。

```
docs/design/in/試合画面-こうしたい.png
docs/design/in/街-背景.png
```

チャットに貼ってもらっても読めるが、**ここに置くほうがよい**。
あとから何度でも読み返せるし、履歴に残るので「前はこう言った」が追える。

---

## 🔴 2種類あって、渡し方が違う

### ① UI（ボタン・パネル・得点板・一覧）→ **指示書として渡す**

絵をそのまま貼り付けることは**しない**。HTML と CSS で組み直す。

理由:
- 文字が**本物の文字**でないと、チーム名の長さが変わったときに崩れる
- 押せる・押せない・選ばれている、といった**状態**が絵では表現できない
- 画面の大きさに合わせて伸び縮みしない

→ なので UI は「**この見た目に寄せてほしい**」という**見本**として渡してもらう。
こちらが数字（色・余白・大きさ）を読み取って組む。

### ② 絵（背景・イラスト・アイコン）→ **そのまま素材として置く**

街・商店街・事務所の背景のような「**絵であることが目的**」のものは、
書き出したものをそのまま `web/bg/` に置いて使う。

🔑 ドット絵の粒を揃えたい場合だけ、`docs/image-prompts.md` の3手順
（960×540へ縮小 → パレットに量子化 → 最近傍で2倍）を通す。

## Canva で作るときの決めごと

| | 推奨 |
|---|---|
| **カンバスの大きさ** | **1920 × 1080**。ゲーム画面と1対1で対応するので、座標がそのまま使える |
| **書き出し** | **PNG** で十分。**SVG が出せるならそちらが最良**（下記） |
| **文字** | レイアウトを見たいので、フォントは何でもよい。ただし下記の注意 |

### SVG が出せるなら、そのほうが精度が上がる

PNG は**絵として読む**ので、色は正確に拾えるが、座標や文字は目で読むことになる。
SVG なら**中の数字がそのまま書いてある**（座標・寸法・色・文字）ので、
「余白が 23px なのか 24px なのか」で迷わない。

PDF でも読める。Canva の無料版で SVG が出せない場合は PNG で問題ない。

### 🔴 フォントはそのまま持ってこられない

このゲームは**外部に通信しない**決まり（要件 §6）なので、Web フォントを読み込めない。
Canva で使ったフォントは、**ファイルを同梱できて、かつライセンスが許す場合のみ**使える。

そうでなければ、ゲームの既定（丸ゴシック系）で組み直す。
**レイアウトと大きさの関係**が分かれば十分なので、フォント違いは気にしなくてよい。

## 🔑 いちばん速いのは「いまの画面に赤入れ」

ゼロから作るより、`current/` のスクリーンショットを Canva に読み込んで、
**その上に書き込む**ほうが圧倒的に伝わる。

```
「ここをもっと大きく」      → 矢印と囲み
「この余白を半分に」        → 寸法線
「この色をこれに」          → 色の四角を隣に置く
「この部分は要らない」      → ✕
```

理由は単純で、**何を変えないかが同時に伝わる**から。
ゼロから描いた絵だと、変えたつもりのない部分まで違っていて、
どこが指示でどこが描き起こしの誤差なのか分からなくなる。

---

## 渡すときに書いてあると助かること（無くてもよい）

絵から読み取れないのはこの3つだけ。

1. **伸びるのはどこか** — チーム名・選手名・一覧は長さが変わる。
   どこが固定幅で、どこが伸びるか
2. **他の状態** — 押したとき／選ばれているとき／空っぽのとき。
   1枚の絵は1つの状態しか写らない
3. **優先順位** — 全部は一度に入らないことがある。
   「ここだけは絶対」が分かると判断が早い

## こちらからの返し方

実装したら、**同じ構図のスクリーンショットを撮って並べて**返す。
`current/` も撮り直すので、次の赤入れはその上からできる。

```
npm run dev          ← 手で触れるサーバー（http://localhost:4174/）
```
